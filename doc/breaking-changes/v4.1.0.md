# Migration Guide: 4.1.0

This guide covers the UI and filter API changes planned for 4.1.0. The package version remains unchanged until the release is prepared.

## Viewer

`showCurlViewer(context)` now opens the full-screen viewer directly. Dialog and bottom-sheet display modes have been removed. The viewer list shows compact request rows; tap a row for its detail page, or expand the arrow to show copy/share actions.

## Bubble

`CurlBubble` now requires `child` and the app's `navigatorKey`. Install it in `MaterialApp.builder`:

```dart
final navigatorKey = GlobalKey<NavigatorState>();

MaterialApp(
  navigatorKey: navigatorKey,
  builder: (context, child) => CurlBubble(
    navigatorKey: navigatorKey,
    child: child ?? const SizedBox(),
  ),
  home: const HomePage(),
)
```

The bubble opens the same viewer as a temporary non-opaque full-screen route. The viewer surface covers the app page, which remains mounted underneath; Back closes the overlay. It no longer uses `BubbleOverlay`, `BubbleStyle`, or `BubbleOverlayController`.

## Filter rule UI/API removal

The viewer no longer manages or previews request filter rules. `FilterOptions`, `FilterRule`, `FilterUtils`, and the filter management UI/service have been removed.

## Viewer state and cache clearing

Viewer search/date/status state is session-only; `enablePersistence` and viewer preferences have been removed. Clear All removes records from the currently active cache box only.
