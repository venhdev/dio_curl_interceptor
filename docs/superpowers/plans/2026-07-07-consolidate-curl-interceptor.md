# Consolidate Curl Interceptor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the duplicated `CurlInterceptor`/`CurlInterceptorV2` pair and `CurlInterceptorFactory` with a single `DioCurlInterceptor` whose internals are split into three peer layers (`DioCurlInterceptor` → `CurlRelay` → sinks), fix seven known bugs, and bump the major version.

**Architecture:** Three layers communicate only through interfaces (`Sink`, `CurlSink`, `MessageSink`). The `DioCurlInterceptor` maps Dio lifecycle into immutable `CurlEvent` data; `CurlRelay` orchestrates dedupe/retry/circuit-breaker; sinks (Discord, Telegram, Hive, Printer, Null) implement `CurlSink` (and `MessageSink` where message-capable). The relay never reads payload; sinks never reference other sinks.

**Tech Stack:** Flutter `>=3.44.0`, Dart `>=3.12.0 <4.0.0`, `dio: ^5.5.0+1`, `hive: ^2.2.3`, `package:logging` (new), `flutter_test` + `mockito: ^5.4.4`.

```dart
class RequestInfo {
  final String method;
  final Uri uri;
  final Map<String, String> headers;
  final String? body;
  final String? curl;
  final Map<String, dynamic> extra;

  const RequestInfo({
    required this.method,
    required this.uri,
    required this.headers,
    required this.body,
    required this.curl,
    required this.extra,
  });

  /// Returns a copy with Authorization/Cookie/Set-Cookie headers stripped
  /// and [curl] rewritten to remove the same headers in-place.
  RequestInfo redactForWebhook() {
    const redactedKeys = {'Authorization', 'Cookie', 'Set-Cookie'};
    final newHeaders = Map<String, String>.fromEntries(
      headers.entries.where((e) => !redactedKeys.contains(e.key)),
    );
    final newCurl = curl == null
        ? null
        : curl!
            .replaceAll(RegExp(r"-H\s+'?-?(Authorization|Cookie|Set-Cookie)[^'\\n]*'?\\s*"), '')
            .replaceAll(RegExp(r"\b(Authorization|Cookie|Set-Cookie)\s*:\s*\S+\s*"), '');
    return RequestInfo(
      method: method,
      uri: uri,
      headers: newHeaders,
      body: body,
      curl: newCurl,
      extra: extra,
    );
  }
}
```

```dart
import 'dart:collection';

/// LRU + TTL cache used to suppress duplicate [CurlEvent] dispatch within the
/// same timeframe. Each entry stores the moment of its most recent touch.
class DedupeCache {
  final Duration ttl;
  final int maxEntries;
  final LinkedHashMap<String, DateTime> _entries = LinkedHashMap();

  DedupeCache({this.ttl = const Duration(minutes: 1), this.maxEntries = 10000});

  /// Returns true if the id has not been dispatched within the TTL, and
  /// records a touch on it. Returns false if the id is still inside the
  /// cooldown window.
  bool shouldDispatch(String id) {
    _evictExpired();
    final now = DateTime.now();
    final last = _entries[id];
    if (last != null && now.difference(last) < ttl) {
      _entries.remove(id); // re-insert at end to mark as most recent
      _entries[id] = last; // preserve original time, just promote position
      return false;
    }
    return true;
  }

  void markDispatched(String id) {
    _entries[id] = DateTime.now();
    if (_entries.length > maxEntries) {
      _entries.remove(_entries.keys.first);
    }
  }

  int get size => _entries.length;

  void _evictExpired() {
    final now = DateTime.now();
    _entries.removeWhere((_, t) => now.difference(t) >= ttl);
  }
}
```

```dart
import 'dart:async';
import 'dart:math';

class RetryExhaustedException implements Exception {
  final String message;
  const RetryExhaustedException(this.message);
  @override
  String toString() => 'RetryExhaustedException: $message';
}

/// Retries an operation with exponential backoff and ±jitter, capped by
/// [maxRetries]. Delays are bounded by [maxDelay]. The [isRetryable] predicate
/// decides which errors are retried; defaults to retry-anything.
class RetryPolicy {
  final int maxRetries;
  final Duration initialDelay;
  final double backoffMultiplier;
  final double jitterFraction;
  final Duration maxDelay;
  final bool Function(Object)? isRetryable;

  RetryPolicy({
    this.maxRetries = 3,
    this.initialDelay = const Duration(seconds: 1),
    this.backoffMultiplier = 2.0,
    this.jitterFraction = 0.2,
    this.maxDelay = const Duration(seconds: 30),
    this.isRetryable,
  });

  Future<T> execute<T>(
    Future<T> Function() op, {
    required String operationName,
  }) async {
    final retry = isRetryable ?? (_) => true;
    Object? lastError;
    var attempt = 0;
    while (true) {
      try {
        return await op();
      } catch (e) {
        lastError = e;
        if (!retry(e) || attempt >= maxRetries) {
          if (attempt >= maxRetries) {
            throw RetryExhaustedException(
              '$operationName failed after $maxRetries retries',
            );
          }
          rethrow;
        }
        await Future<void>.delayed(_delayFor(attempt));
        attempt++;
      }
    }
  }

  Duration _delayFor(int attempt) {
    final base = initialDelay.inMilliseconds *
        pow(backoffMultiplier, attempt).toDouble();
    final capped = base.clamp(0, maxDelay.inMilliseconds).toInt();
    final jitterRange = (capped * jitterFraction).toInt();
    final jitter = jitterRange == 0
        ? 0
```

```dart
enum CircuitState { closed, open, halfOpen }

class CircuitOpenException implements Exception {
  final String message;
  const CircuitOpenException(this.message);
  @override
  String toString() => 'CircuitOpenException: $message';
}

/// Per-sink circuit breaker. Tracks consecutive failures; opens at
/// [failureThreshold]. After [resetTimeout] the next call tries in
/// [halfOpen]: success closes, failure reopens.
class CircuitBreaker {
  final int failureThreshold;
  final Duration resetTimeout;

  CircuitState _state = CircuitState.closed;
  int _consecutiveFailures = 0;
  DateTime _openedAt = DateTime.fromMillisecondsSinceEpoch(0);

  CircuitBreaker({
    this.failureThreshold = 5,
    this.resetTimeout = const Duration(minutes: 1),
  });

  CircuitState get state => _state;
  int get failureCount => _consecutiveFailures;

  Future<T> call<T>(Future<T> Function() op) async {
    if (_state == CircuitState.open) {
      if (DateTime.now().difference(_openedAt) >= resetTimeout) {
        _state = CircuitState.halfOpen;
      } else {
        throw CircuitOpenException('circuit open');
      }
    }
    try {
      final result = await op();
      _onSuccess();
      return result;
    } catch (e) {
      _onFailure();
      rethrow;
    }
  }

  void _onSuccess() {
    _consecutiveFailures = 0;
    _state = CircuitState.closed;
  }

  void _onFailure() {
    _consecutiveFailures++;
    if (_state == CircuitState.halfOpen || _consecutiveFailures >= failureThreshold) {
      _state = CircuitState.open;
      _openedAt = DateTime.now();
    }
  }
}
```

```dart
/// Sends cURL events (and arbitrary messages) to Discord webhook URLs.
/// Uses a dedicated Dio (not the user's app Dio) to avoid re-triggering the
/// interceptor chain. Redacts Authorization/Cookie headers before send.
class DiscordSink implements CurlSink, MessageSink {
  final List<String> webhookUrls;
  final SenderInfo? senderInfo;
  final DiscordInspector _inspector;

  DiscordSink({
    required this.webhookUrls,
    Dio? dio,
    this.senderInfo,
  }) : _inspector = DiscordInspector(
          webhookUrls: webhookUrls,
          dio: dio ?? Dio(),
        );

  @override
  String get name => 'Discord:${webhookUrls.isNotEmpty ? webhookUrls.first : "none"}';

  @override
  Future<void> handle(CurlEvent event) async {
    final redacted = event.request.redactForWebhook();
    final redactedOpts = _toRequestOptions(redacted);
    final response = event is ResponseCurlEvent ? event.response : null;
    final error = event is ErrorCurlEvent ? event.error : null;

    await _inspector.inspectOn(
      options: redactedOpts,
      response: response == null
          ? null
          : Response<dynamic>(
              requestOptions: redactedOpts,
              data: response.body,
              statusCode: response.statusCode,
            ),
      err: error == null
          ? null
          : DioException(
              requestOptions: redactedOpts,
              type: DioExceptionType.unknown,
              message: error.message,
              response: error.statusCode == null
                  ? null
                  : Response<dynamic>(
                      requestOptions: redactedOpts,
                      statusCode: error.statusCode,
                    ),
            ),
      senderInfo: senderInfo,
    );
  }

  @override
  Future<void> sendMessage(String content, {SenderInfo? senderInfo}) async {
    await _inspector.sendMessage(
      content: content,
      senderInfo: senderInfo ?? this.senderInfo,
    );
  }

  @override
  Future<void> dispose() async {
    _inspector.dispose?.call();
  }
}

RequestOptions _toRequestOptions(RequestInfo ri) {
  final opts = RequestOptions(
    method: ri.method,
    path: ri.uri.toString(),
  );
  opts.headers.addAll(ri.headers);
  if (ri.body != null) opts.data = ri.body;
  return opts;
}
```

```dart
            data: resp.body,
            statusCode: resp.statusCode,

    final dioErr = err == null
        ? null

            requestOptions: opts,
            type: DioExceptionType.unknown,
            message: err.message,
            response: err.statusCode == null
```

```dart
import 'dart:async';

import '../data/models/sender_info.dart';
import '../events/curl_event.dart';
import '../sinks/curl_sink.dart';
import '../sinks/message_sink.dart';
import '../sinks/sink.dart';
import '../util/log.dart';
import 'circuit_breaker.dart';
import 'dedupe_cache.dart';
import 'retry_policy.dart';

class RelayOptions {
  final bool retry;
  final bool circuitBreaker;
  final Duration? dedupeTtl;
  final int retryMaxRetries;
  final Duration retryInitialDelay;
  final double retryBackoffMultiplier;
  final double retryJitterFraction;
  final Duration retryMaxDelay;
  final int circuitFailureThreshold;
  final Duration circuitResetTimeout;
  final int dedupeMaxEntries;

  const RelayOptions({
    this.retry = true,
    this.circuitBreaker = true,
    this.dedupeTtl = const Duration(minutes: 1),
    this.retryMaxRetries = 3,
    this.retryInitialDelay = const Duration(seconds: 1),
    this.retryBackoffMultiplier = 2.0,
    this.retryJitterFraction = 0.2,
    this.retryMaxDelay = const Duration(seconds: 30),
    this.circuitFailureThreshold = 5,
    this.circuitResetTimeout = const Duration(minutes: 1),
    this.dedupeMaxEntries = 10000,
  });

  const RelayOptions.disabled()
      : retry = false,
        circuitBreaker = false,
        dedupeTtl = null,
        retryMaxRetries = 0,
        retryInitialDelay = Duration.zero,
        retryBackoffMultiplier = 1.0,
        retryJitterFraction = 0.0,
        retryMaxDelay = Duration.zero,
        circuitFailureThreshold = 5,
        circuitResetTimeout = const Duration(minutes: 1),
        dedupeMaxEntries = 0;
}

class CurlRelay {
  final List<Sink> sinks;
  final RelayOptions options;
  final DedupeCache _dedupe;
  final RetryPolicy? _retry;
  final Map<String, CircuitBreaker> _breakers = {};
  final Set<Future<void>> _inFlight = {};
  bool _disposed = false;

  CurlRelay({
    required this.sinks,
    this.options = const RelayOptions(),
  })  : _dedupe = DedupeCache(
            ttl: options.dedupeTtl ?? const Duration(minutes: 1),
            maxEntries: options.dedupeMaxEntries),
        _retry = options.retry
            ? RetryPolicy(
                maxRetries: options.retryMaxRetries,
                initialDelay: options.retryInitialDelay,
                backoffMultiplier: options.retryBackoffMultiplier,
                jitterFraction: options.retryJitterFraction,
                maxDelay: options.retryMaxDelay,
              )
            : null;

  void dispatch(CurlEvent event) {
    if (_disposed) return;
    if (options.dedupeTtl != null) {
      if (!_dedupe.shouldDispatch(event.id)) return;
      _dedupe.markDispatched(event.id);
    }
    unawaited(_runForEvent(event));
  }

  Future<void> sendMessage(
    String content, {
    SenderInfo? senderInfo,
    List<String>? targetSinks,
  }) async {
    if (_disposed) return;
    final targets = sinks.whereType<MessageSink>().where((s) =>
        targetSinks == null || targetSinks.contains(s.name));
    for (final sink in targets) {
      unawaited(_runForSend(sink, content, senderInfo));
    }
  }

  Future<void> dispose() async {
    if (_disposed) return;
    _disposed = true;
    await Future.wait(_inFlight).timeout(const Duration(seconds: 5), onTimeout: () {});
    for (final s in sinks.reversed) {
      try { await s.dispose(); } catch (_) {}
    }
    _breakers.clear();
  }

  Future<void> _runForEvent(CurlEvent event) async {
    final f = _fanOut(event);
    _inFlight.add(f);
    try { await f; } finally { _inFlight.remove(f); }
  }

  Future<void> _runForSend(MessageSink sink, String content, SenderInfo? info) async {
    final f = _fanOutMessage(sink, content, info);
    _inFlight.add(f);
    try { await f; } finally { _inFlight.remove(f); }
  }

  Future<void> _fanOut(CurlEvent event) async {
    for (final sink in sinks.whereType<CurlSink>()) {
      try {
        if (options.circuitBreaker) {
          final cb = _breakers.putIfAbsent(
            sink.name,
            () => CircuitBreaker(
              failureThreshold: options.circuitFailureThreshold,
              resetTimeout: options.circuitResetTimeout,
            ),
          );
          await cb.call(() => _withRetry(() => sink.handle(event), 'sink:${sink.name}'));
        } else {
          await _withRetry(() => sink.handle(event), 'sink:${sink.name}');
        }
      } catch (e, st) {
        logger.warning('Sink ${sink.name} failed: $e', error: e, stackTrace: st);
      }
    }
  }

  Future<void> _fanOutMessage(MessageSink sink, String content, SenderInfo? info) async {
    try {
      if (options.circuitBreaker) {
        final cb = _breakers.putIfAbsent(
          sink.name,
          () => CircuitBreaker(
            failureThreshold: options.circuitFailureThreshold,
            resetTimeout: options.circuitResetTimeout,
          ),
        );
        await cb.call(() => _withRetry(() => sink.sendMessage(content, senderInfo: info), 'msg:${sink.name}'));
      } else {
        await _withRetry(() => sink.sendMessage(content, senderInfo: info), 'msg:${sink.name}');
      }
    } catch (e, st) {
      logger.warning('Message sink ${sink.name} failed: $e', error: e, stackTrace: st);
    }
  }

  Future<T> _withRetry<T>(Future<T> Function() op, String name) async {
    if (_retry == null) return op();
    return _retry.execute(op, operationName: name);
  }
}
```

```dart
import 'package:dio/dio.dart';

import 'config/curl_config.dart';
import 'data/models/sender_info.dart';
import 'events/curl_event.dart';
import 'events/error_info.dart';
import 'events/request_info.dart';
import 'events/response_info.dart';
import 'relay/curl_relay.dart';
import 'util/intercept_safe.dart';

class DioCurlInterceptor extends Interceptor {
  final CurlConfig config;
  final CurlRelay relay;
  final Map<String, Stopwatch> _stopwatches = {};
  final Random _rng = Random();

  DioCurlInterceptor({
    required this.config,
    CurlRelay? relay,
  }) : relay = relay ?? CurlRelay(sinks: config.sinks, options: config.relayOptions);

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    InterceptSafe.run('onRequest', () {
      final id = options.extra['curlEventId']?.toString() ?? _newId();
      options.extra['curlEventId'] = id;
      if (config.responseTime) {
        _stopwatches[id] = Stopwatch()..start();
      }
      final event = RequestCurlEvent(
        id: id,
        timestamp: DateTime.now(),
        request: RequestInfo.fromOptions(options),
      );
      relay.dispatch(event);
    });
    handler.next(options);
  }

  @override
  void onResponse(Response response, ResponseInterceptorHandler handler) {
    InterceptSafe.run('onResponse', () {
      final id = response.requestOptions.extra['curlEventId']?.toString() ?? '';
      final sw = _stopwatches.remove(id);
      sw?.stop();
      final event = ResponseCurlEvent(
        id: id,
        timestamp: DateTime.now(),
        request: RequestInfo.fromOptions(response.requestOptions),
        response: ResponseInfo(
          statusCode: response.statusCode ?? -1,
          headers: _stringHeaders(response.headers.map),
          body: response.data,
          duration: sw?.elapsed ?? Duration.zero,
        ),
      );
      relay.dispatch(event);
    });
    handler.next(response);
  }

  @override
  void onError(DioException err, ErrorInterceptorHandler handler) {
    InterceptSafe.run('onError', () {
      final id = err.requestOptions.extra['curlEventId']?.toString() ?? '';
      final sw = _stopwatches.remove(id);
      sw?.stop();
      final event = ErrorCurlEvent(
        id: id,
        timestamp: DateTime.now(),
        request: RequestInfo.fromOptions(err.requestOptions),
        error: ErrorInfo(
          type: err.type.name,
          message: err.message ?? '',
          statusCode: err.response?.statusCode,
        ),
        response: err.response == null
            ? null
            : ResponseInfo(
                statusCode: err.response!.statusCode ?? -1,
                headers: _stringHeaders(err.response!.headers.map),
                body: err.response!.data,
                duration: sw?.elapsed ?? Duration.zero,
              ),
      );
      relay.dispatch(event);
    });
    handler.next(err);
  }

  Future<void> sendMessage(
    String content, {
    SenderInfo? senderInfo,
    List<String>? targetSinks,
  }) async {
    InterceptSafe.run('sendMessage', () {
      relay.sendMessage(content, senderInfo: senderInfo, targetSinks: targetSinks);
    });
  }

  Future<void> dispose() async {
    _stopwatches.clear();
    await relay.dispose();
  }

  String _newId() {
    final r = _rng;
    final values = List<int>.generate(16, (_) => r.nextInt(256));
    return values.map((b) => b.toRadixString(16).padLeft(2, '0')).join();
  }
}

Map<String, String> _stringHeaders(Map<String, List<String>> h) {
  return h.map((k, v) => MapEntry(k, v.join(', ')));
}
```

```markdown
## 4.0.0

### BREAKING

- `CurlInterceptor`, `CurlInterceptorV2`, and `CurlInterceptorFactory` have been removed.
- New public API: `DioCurlInterceptor(config: CurlConfig(...))`.
- `webhook_inspector_base.dart`, `discord_inspector.dart`, and `telegram_inspector.dart` are deprecated and will be removed in 5.0.0. Use `DiscordSink`, `TelegramSink`, etc. from `package:dio_curl_interceptor/sinks/`.

### Features

- Three-layer architecture: interceptor → relay → sinks.
- Per-sink circuit breaker, exponential retry with jitter, LRU dedupe.
- `DiscordSink` and `TelegramSink` redact `Authorization` and `Cookie` headers before webhook send.
- `interceptor.sendMessage(content)` for manual, non-HTTP messages.
- Logging via `package:logging` (configure via `Logger('CurlInterceptor').onRecord`).

### Bug fixes

- One HTTP response now triggers exactly one webhook (no double-dispatch).
- `response.duration` reflects real elapsed time instead of `N/A`.
- `DedupeCache` is LRU-bounded at 10 000 entries.
- Telegram sink cache key is `(botToken, sortedChatIds)` — no more token-prefix collisions.

### Migration

- See `docs/superpowers/specs/2026-07-07-consolidate-curl-interceptor-design.md`.
```
